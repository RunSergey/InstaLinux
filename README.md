# 📦 InstaLinux — Универсальный графический установщик для Ubuntu / Debian

**InstaLinux** — это приложение с современным интерфейсом (GTK 4 / Libadwaita), которое упрощает установку и управление программами в Linux для пользователей, перешедших с других операционных систем.

---

### ✨ Возможности

- **Drag & Drop**: просто перетащите файл прямо в окно программы или нажмите кнопку «Выбрать файл».
- **Широкая поддержка форматов**:
  - 📦 `.deb` — установка системных пакетов с авторазрешением зависимостей через APT/dpkg.
  - 🚀 `.AppImage` — автоматическая выдача прав на запуск (`chmod +x`), размещение и интеграция в меню.
  - 🗜️ **Архивы** (`.tar.gz`, `.zip`, `.tar.xz`, `.tar.bz2`, `.tar`) — автораспаковка, поиск главного бинарника и иконки.
  - ⚙️ **Скрипты и бинарники** (`.sh`, `.run`, `.bin`) — безопасная установка исполняемых файлов.
- **Гибкая настройка**:
  - Смена названия программы.
  - Выбор или замена иконки (PNG, SVG).
  - Выбор категории в системном меню (Офис, Разработка, Игры, Интернет и т.д.).
  - Выбор области установки: **Только для меня** (`~/.local/share/`, не требует прав root) или **Для всей системы** (`/opt/`).
  - Опция запуска в терминале (для CLI-утилит).
- **Менеджер установленных программ**:
  - Просмотр всех программ, установленных через InstaLinux.
  - Открытие папки с программой в один клик.
  - Полное и чистое удаление программы и её ярлыков.

---

### 🚀 Быстрая установка

Чтобы установить InstaLinux на текущий или любой другой компьютер (Ubuntu/Debian):

```bash
git clone <ссылка-на-репозиторий>
cd InstaLinux
./install.sh
```

Скрипт автоматически:
1. Проверит и доустановит необходимые зависимости (`python3-gi`, `gir1.2-gtk-4.0`, `gir1.2-adw-1` и утилиты архивации).
2. Создаст исполняемый файл `instalinux` в `~/.local/bin/`.
3. Добавит ярлык с иконкой в системное меню приложений.

После этого программа будет доступна в меню приложений под именем **InstaLinux** или по команде в терминале:
```bash
instalinux
```

---

### 🗑️ Удаление InstaLinux

Если потребуется удалить сам установщик InstaLinux:
```bash
./uninstall.sh
```
